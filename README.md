# 管道弯头自动放样小程序

一个用于**虾米弯（多节焊接弯头）自动放样**的桌面小工具。根据设计院图纸给出的弯头角度、外径、壁厚以及**每一节的长边/短边**，自动完成斜切角、中线长、弯曲半径反推、一致性校验，并生成 **弯管图 / 单V坡口接口示意图 / 下料放样图**，输出可被 CAD 读取的 **DXF**。

该项目由 tkinter 驱动，**不依赖任何第三方 GUI 库**；DXF 输出为自实现的 ASCII DXF 生成器，**无需安装 ezdxf**。

---

## 功能特性

- **图纸驱动**：输入每节的长边/短边，自动反推斜切角 φ、中线长 L0、弯曲半径 R。
- **一致性校验**：检查各节 φ 是否统一、Σ方向改变是否等于弯头角；并说明“Σ中心角 ≠ 弯头角”在弦布置下属正常。
- **单V坡口**：坡口半角 θ、钝边 p、根部间隙 g，恒定近似计算坡口余量 W=(t−p)·tanθ。
- **三种视图**：
  - **弯管图**：直管段（虾米弯）表示，含进出口直管、整体尺寸链、圆心与 R（圆心到两端距离 = R）。
  - **坡口/接口示意**：单V坡口横截面，尺寸标注。
  - **放样图·下料**：每节的外皮展开图（理论线 + 含坡口余量的下切线），无重叠。
- **需用直管长度**：主数据 = Σ每节长边（每节至少要按自身长边切出），同时给出含坡口余量、中心线几何合计、装配总长。
- **DXF 输出**：一键导出放样 DXF，并可用 AutoCAD 直接打开。

## 一键启动（免安装 EXE）

仓库 `release/` 内已附带打包好的 **Windows 一键启动程序**：

```
release/弯头放样工具V2.exe
```

- **免安装 Python、免命令行**，直接双击运行。
- 也可以用 x64 版本的 **PyInstaller 打包**（见下文“打包成 EXE”）。
- 若需在其它电脑使用，直接下载该 `.exe` 运行即可（Windows 10/11，64 位）。

> 提示：这是用 PyInstaller `--onefile --windowed` 打包的单文件程序，首次启动因解压内嵌运行时可能稍慢几秒，属正常。

## 界面用法（GUI）

运行后主界面：

- **左侧**：弯头参数（弯头角 α、外径 OD、壁厚 t、节数 N、弯曲半径 R、坡口半角 θ、钝边 p、根部间隙 g）
  - 每节可编辑表：**类型**（半节/全节）、**长边**、**短边**、**中心角°**（留空自动反推）
  - 主数据「需用直管」（Σ每节长边）放大显示
  - 按钮：【自动计算】【生成（用表中的长/短边）】【输出放样图 DXF】【用 AutoCAD 打开】
- **右侧三个页签**：【弯管图】【坡口/接口示意】【放样图·下料】

流程：填 弯头角 + 段数 →【自动计算】出默认弯管图 → 在表格中改各节长/短边 →【生成】重新画出数据吻合的弯管图 → 切到【坡口接口】【放样图】查看 →【输出放样图 DXF】→【用 AutoCAD 打开】。

## 计算口径说明

- 长边/短边为**外皮（OD）基准**、**不含坡口**（坡口根/钝边基准）。
- 斜切角：半节 `tanφ=(长边−短边)/OD`；全节 `tanφ=(长边−短边)/(2·OD)`。
- 弯曲半径 R：按中心线弧长约定，`R=L0/中心角`；设计给出的 R 用于画弯管图。
- 需用直管 = **Σ每节长边**；含坡口 = Σ每节下料长边；中心线几何合计 = Σ中线（参考）。
- “Σ每节中心角 ＞ 弯头角”在直管（弦）布置下属正常现象，不影响放样。
