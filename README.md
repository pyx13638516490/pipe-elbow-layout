# 管道弯头自动放样小程序

一个用于**虾米弯（多节焊接弯头）自动放样**的桌面小工具。根据设计院图纸给出的弯头角度、外径、壁厚以及**每一节的长边/短边**，自动完成斜切角、中线长、弯曲半径反推、一致性校验，并生成 **弯管图 / 单V坡口接口示意图 / 下料放样图**，输出可被 CAD 读取的 **DXF**。

该项目界面由 tkinter 驱动（**无需第三方 GUI 库**）；DXF 输出用成熟的 **ezdxf** 生成**标准合法 DXF（R2010）**，AutoCAD 可直接打开；另支持 **SVG** 输出（浏览器/Inkscape 直接打开）。

---

## 功能特性

- **图纸驱动**：输入每节的长边/短边，自动反推斜切角 φ、中线长 L0、弯曲半径 R。
- **一致性校验**：检查各节 φ 是否统一、Σ方向改变是否等于弯头角；并说明“Σ中心角 ≠ 弯头角”在弦布置下属正常。
- **单V坡口**：坡口半角 θ、钝边 p、根部间隙 g，恒定近似计算坡口余量 W=(t−p)·tanθ。
- **三种视图**：
  - **弯管图**：直管段（虾米弯）表示，含进出口直管、整体尺寸链、圆心与 R（圆心到两端距离 = R）。
  - **坡口/接口示意**：单V坡口横截面，尺寸标注。
  - **放样图·下料**：每节的外皮展开图（理论线 + 含坡口余量的下切线），**按 1:1(mm) 绘制**，可绕钢管下料。
- **CAD 标注**：放样图用 **CAD 原生线性尺寸标注**（带箭头+数值）自动标注**每一节的最长边/最短边**（含下料尺寸），无需手动量取。
- **导出**：
  - **DXF**：用 ezdxf 生成标准合法 DXF（R2010），**CAD 可直接打开**；标注为中文（宋体字形）、行距避免重合。
  - **SVG**：输出 SVG 矢量图，浏览器/Inkscape 可直接打开，无需 CAD。
- **曲线精度**：斜切展开曲线为精确正弦（振幅=(OD/2)·tanφ，周期=外皮周长 π×OD），逐点逼近最大偏差 ≤0.02mm，可直接贴管下料。
- **曲线验证**：自带 `verify.py`，可逐节逐点核对曲线/长边/短边/宽度是否严格 1:1。
- **需用直管长度**：主数据 = Σ每节长边（每节至少要按自身长边切出），同时给出含坡口余量、中心线几何合计、装配总长。
- **DXF 输出**：一键导出放样 DXF，并可用 AutoCAD 直接打开。

## 一键启动（免安装 EXE）

仓库 `release/` 内已附带打包好的 **Windows 一键启动程序**：

```
release/弯头放样工具V2.exe
```

> 提示：这是用 PyInstaller `--onefile --windowed` 打包的单文件程序，首次启动因解压内嵌运行时可能稍慢几秒，属正常。

## 界面用法（GUI）

运行后主界面：

- **左侧**：弯头参数（弯头角 α、外径 OD、壁厚 t、节数 N、弯曲半径 R、坡口半角 θ、钝边 p、根部间隙 g）
  - 每节可编辑表：**类型**（半节/全节）、**长边**、**短边**、**中心角°**（留空自动反推）
  - 主数据「需用直管」（Σ每节长边）放大显示
  - 按钮：【自动计算】【生成（用表中的长/短边）】【输出放样图 DXF】【用 AutoCAD 打开】
- **右侧三个页签**：【弯管图】【坡口/接口示意】【放样图·下料】

流程：填 弯头角 + 段数 →【自动计算】出默认弯管图 → 在表格中改各节长/短边 →【生成】重新画出数据吻合的弯管图 → 切到【坡口接口】【放样图】查看 →【输出放样图 DXF】→【用 AutoCAD 打开】。

## 命令行方式（CLI）

```
# 从包父目录运行
python -m elbow_layout.main <config.json> [--open-cad] [--out <dir>]
```

示例配置见 `configs/demo_90.json`。

### 验证放样图曲线（可选）
```
python verify.py                 # 用内置演示数据
python verify.py <config.json>   # 用你自己的配置
```
会逐节核对：宽度=π×OD、长边/短边、曲线逐点偏差，并给出是否 1:1 合格。

## 项目结构

```
elbow_layout/
├─ models.py     数据模型（每节、弯头输入）
├─ geometry.py   核心几何引擎（φ、中线长、R、中心角、一致性、截面/拼线）
├─ dxfout.py     ezdxf 生成标准 DXF + CAD 线性尺寸标注
├─ layout.py     放样图 → DXF 输出（1:1、中文标注、CAD尺寸）
├─ render.py     三种视图的绘制指令（弯管图/坡口/放样图）与 Canvas/SVG 渲染
├─ report.py     文本报告 + 材料汇总
├─ cad.py        查找并启动 AutoCAD
├─ gui.py        简单版图形界面（V1）
├─ gui2.py       高交互图形界面（V2, 主界面）
├─ main.py       CLI 入口
├─ verify.py     放样图曲线/尺寸验证脚本
├─ launcher.py   PyInstaller 入口（V1）
├─ launcher2.py  PyInstaller 入口（V2）
├─ configs/      示例配置 JSON
└─ release/      打包好的 Windows 一键启动 EXE（弯头放样工具V2.exe）
```

## 计算口径说明

- 长边/短边为**外皮（OD）基准**、**不含坡口**（坡口根/钝边基准）。
- 斜切角：半节 `tanφ=(长边−短边)/OD`；全节 `tanφ=(长边−短边)/(2·OD)`。
- 弯曲半径 R：按中心线弧长约定，`R=L0/中心角`；设计给出的 R 用于画弯管图。
- 需用直管 = **Σ每节长边**；含坡口 = Σ每节下料长边；中心线几何合计 = Σ中线（参考）。
- “Σ每节中心角 ＞ 弯头角”在直管（弦）布置下属正常现象，不影响放样。
